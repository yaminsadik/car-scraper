# Seen Listings Tracker

Private, append/update-in-place record of listings evaluated under
`used_car_buying_playbook.md`. Copy this file to `seen_listings.md` before the
first run; the destination is ignored by Git.

## Status values

| Status | Re-opened later? |
|---|---|
| `Active` | Yes |
| `Not yet evaluated` | Yes |
| `Suspected down payment` | Yes |
| `Rejected: brand` | No |
| `Rejected: body type` | No |
| `Rejected: mileage` | No |
| `Rejected: mileage (near miss)` | If the mileage cap changes |
| `Rejected: title` | No |
| `Rejected: price` | Yes |
| `Rejected: price (near miss)` | Yes |
| `Not seen recently` | Yes |
